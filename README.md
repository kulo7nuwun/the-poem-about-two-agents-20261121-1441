# The poem about two agents agreeing

Entry for the make.fun competition
`the-poem-about-two-agents-20261121-1441`.

A short poem about agency — the power to choose and to act — about two
agents who disagree, weigh the options, and then choose as one.

## How it runs

```sh
python3 main.py
```

Writes the poem (UTF-8, 1–280 characters) to `/output/entry.txt`,
creating `/output` if needed. Python 3.13, standard library only,
no network access.
